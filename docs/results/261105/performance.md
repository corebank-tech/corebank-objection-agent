# 이의제기 AI 심사 지원 성과 수치 (11/5 평가)

장표용 핵심 수치와 근거. 상세는 `evaluation.md`, 원자료는 `results-all.json`, 정답은 `eval/manifest.json`(실행 전 확정).
평가 대상: 합성 시나리오 24건(정상 6, 대포통장 5, 소명과 원장 모순 5, 규칙 경계 2, 인젝션 3, 근거 없음 3), Opus 5.5 건당 3회.

## 장표 문장 예시

- 사기 계좌 7건 중 해제 0건. 서류만으로 수용하는 방식이면 7건 모두 해제된다.
- 규칙이 통과시키는 거짓 소명 15건 중 15건을 AI가 원장과 대조해 찾아냈다. 키워드 규칙으로는 0건이다.
- AI 판정안 정확도 96%, 같은 사건 3회 반복 일치 100%, 근거 날조 0건.
- 건당 $0.04, 17초.

## 숫자를 말할 때 함께 말할 것

- 합성 시나리오 24건이고 정답은 설계자가 정했다. 같은 건 3회 실행은 독립 표본이 아니다.
- 오탐 3회는 정답 표의 누락이었다(M2, `evaluation.md` 결과 해석). 고치지 않은 원래 수치를 쓴다.
- Sonnet과 Haiku는 1회씩만 돌렸다. Haiku는 비용이 24분의 1이지만 오탐과 조사 깊이 문제가 보여 기본 모델로 바꾸지 않는다.
- 규칙 기준값(송금인 3명, 60분 안 80% 출금, 관계 거래 3회 등)은 은행 내부 기준을 가정한 값이다.
