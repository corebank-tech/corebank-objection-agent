# AI 심사 지원 거버넌스

지급정지 이의제기 AI 심사 지원이 금융권 AI 운영 원칙을 어떻게 지키는지 정리한다. 기준은 2026년 6월 개정된 금융위원회 「금융분야 인공지능 가이드라인」의 7대 원칙과 2023년 금융보안원 「금융분야 AI 보안 가이드라인」이다. 원문 조항은 확인하지 않았고 보도된 원칙 이름과 요지를 기준으로 했다.

## 원칙

- AI는 원장 대조 결과와 판정 의견만 낸다. 계좌를 바꾸지 않고 어떤 판정도 막지 않는다.
- 해제는 은행 규칙인 해제 요건 점검이 근거를 확인하거나, 담당자가 사유를 남기고 다른 관리자가 승인했을 때만 열린다.
- 최종 판정과 책임은 사람에게 있다.

## 사람이 확인하는 지점

| 순서 | 지점 | 사람이 하는 일 | AI의 몫 |
|---|---|---|---|
| 1 | 소명 완비 확인 | 서류가 갖춰졌는지 확인하고 심사 기한을 연다 | 없음 |
| 2 | 판정 작성 | AI 의견, 규칙 결과, 원장을 보고 판정과 사유를 쓴다 | 주장 정리, 원장 대조, 모순 제시, 판정 의견 |
| 3 | 재량 판정 | 규칙이 닫은 해제를 열려면 사유를 20자 이상 남긴다 | 없음 |
| 4 | 2인 승인 | 작성자가 아닌 관리자가 확인하고 확정한다. 재량 판정은 사유 확인을 따로 체크한다 | 없음 |

재량 판정으로도 넘을 수 없는 요건이 있다. 소송 계속, 사유 조항과 판정 범위 불일치, 외부 기관의 부정 회신이다.

## 7대 원칙 대응

| 원칙 | 이 시스템의 대응 |
|---|---|
| 거버넌스 | AI 사용 범위를 심사 보조로 한정. 킬스위치 `PAYMENT_STOP_AGENT_ENABLED`는 기본 꺼짐. 모델과 프롬프트 버전을 판정안마다 기록 |
| 합법성 | 사유 조항, 소송 계속, 신청 기한 같은 법정 요건은 규칙으로만 판단하고 AI와 재량 판정으로 바꾸지 못함 |
| 보조수단성 | AI 판정안은 「AI 의견(참고)」로만 표시. 판정 작성과 승인은 사람 |
| 신뢰성 | 정답을 실행 전에 확정한 평가 세트로 버전마다 재측정. 모델만 정확도와 보정 뒤 정확도를 나눠 `docs/results/`에 보고 |
| 금융안정성 | AI 오류가 해제로 이어지지 않도록 규칙 점검, 보정 규칙, 2인 승인을 겹쳐 둠. 분석 실패는 수동 심사로 되돌아감 |
| 신의성실 | 명의인에게 보내는 안내문 초안은 해제를 약속하지 않음. 고객 화면에 AI 판단 결과를 직접 보이지 않음 |
| 보안성 | 가명 처리, 프롬프트 인젝션 방어, 작업 토큰과 워커 키, 내부 API 외부 차단, 비밀값 저장소 미보관 |

## 가명 처리를 하는 이유

- 판정 의견을 만드는 모델은 은행 밖 서비스다. 고객 개인정보가 은행 밖으로 나가지 않아야 한다.
- 서버가 소명과 서류 글에서 주민등록번호, 연락처, 이메일, 계좌번호 형태를 자리표시로 바꾸고, 상대 계좌는 `CP-`로 시작하는 가명 키로만 보낸다. 같은 상대는 같은 키라 관계 거래 분석은 그대로 된다.
- 신분증 사본은 분석에 넣지 않고 암호화해 저장한다. 서류 원본 이미지는 모델에 보내지 않고 글자 인식 결과만 가명 처리해 보낸다.
- 남은 범위: 서류 글의 이름과 주소는 형태가 정해져 있지 않아 가려지지 않는다. 운영 전에 마스킹 범위를 개인정보 담당과 정해야 한다.

## 기록

| 항목 | 위치 |
|---|---|
| 분석 단계, 도구 호출 이유, 조회 조건, 결과 요약 | `agent_run_step` |
| 판정 의견, 모델, 프롬프트 버전, 토큰, 비용 | `review_draft` |
| 보정 규칙이 바꾼 내역 | 판정안 제출 단계의 `branchAdjustments` |
| 판정, 재량 여부와 사유, 작성 당시 규칙 결과, 승인자 | `objection_decision` |
| 서류 열람, 재량 판정 작성과 승인 | 관리자 감사 기록 |

## 모델 선택

- 지금은 상용 모델 Claude를 쓴다. 분석기는 `objection_agent/llm/port.py`의 포트 뒤에 있어 은행 안에서 운영하는 공개 모델로 바꿀 수 있다. 금융권은 Qwen 같은 모델을 내부에서 운영하기도 한다.
- 바꿀 때는 같은 평가 세트로 다시 재고 위 신뢰성 기준을 다시 확인한다.
